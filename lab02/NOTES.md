Рабочая папка - это папка для сохранения разных текущих рабочих файлов
Индекс - это показатель, который указывает на место элемента, база данных
Коммит - сохраненный снапшот состояния проекта в определенный момент времени



Различие между Git и GitHub заключается в том, что Git это программа для отслеживания  изменений в коде, а GitHub это веб-сайт для совместной работы и хранения проектов

&#x20;

Использование команды: 

git status - показывает текущее состояние репозитория

git diff - показывает различия между разными состояниями файлов коммита

git diff --staged - показывает изменения,которые уже добавлены в staging area?\\, но еще не попали в комит



Ветки:

ветка - это указатель на последовательность коммита

слияние - это объединение изменения одной ветки с другой 

при новом коммите ветка перемещается
